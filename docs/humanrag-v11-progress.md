## 已确认的共享根因

- 开场用 phase 切换 SceneModel，导航与 Universe 界面在路由交接后才挂载；需要将最终界面预备在同一空间壳内。
- CameraControls 的 stop 会直接采用旧目标终点；setLookAt 未归一化累积方位角。
- 两套流光分别在 pointer/wheel 时冻结时钟和终止脉冲。
- 知识点题库返回把节点 ID 当过滤条件传给父页，错误缩小父级题库。
- V9 领域数据与 V7 ContentRepository 有读取边界；扩展学习入口之前要核对用户节点读取与旧数据兼容。

## G2 空间连续性基础（2026-09-11）

- 最终 SceneModel、Canvas、导航和 Universe 界面先挂载；进入只撤去覆盖层并运行 1.7 秒镜头，不再在结束时跳路由。导航获得焦点，低动态模式直接进入。
- 相机归一化累积方位角，并取跨 ±π 的最短路径；输入捕获时保留当前位姿和偏移，替代会跳到旧终点的 stop。
- 一个 ResizeObserver 读取导航和详情面板尺寸；真实节点仍为轨道中心，通过 focal offset 放到有效视区中心。节点切换保留详情外壳，退出内容 inert，关闭同时请求全景。
- 突触脉冲合入同一连线 shader，使用真实曲线进度和渲染时钟；移除重复的 NeuralSignals 组件及旧测试，可由 Git 恢复。拖动不暂停流光。几何缓存与外观更新分开；层级遍历改为邻接表和队列游标。
- 父子页面使用成对 24px 深度过渡；移动开场 CTA 不再位于变换后的标题容器，删除将 Universe 推成额外一屏的重复定位规则。
- 类型检查、149 项单测通过；相机使用真实 CameraControls 测试累积旋转、跨边界、中断和桌面/底部面板投影。
- 13 项相关浏览器用例通过，覆盖三种宽度各五轮导航；最终补充的 4 项空间测试也全部通过，证明开场前后 Canvas/导航/UI 身份相同、焦点交接、低动态进入、1440/390 连续三次节点切换时详情外壳不重建且投影居中。
