# iTeach 空间知识图册视觉施工规范 V2（已废止）

> 本规范的浅色纸面、顶部方向选择器、固定 HUD、矩形层级框和固定侧栏方案已被最新需求否定。自 2026-08-25 起，产品定位、黑色视觉、交互和响应式实现以 [knowledge-neural-space-v3-foundation.md](./knowledge-neural-space-v3-foundation.md) 为准。本文仅保留历史设计记录，不得继续作为施工依据。

## 1. 设计定位

产品不是星空或星球模拟器，也不是把 Dashboard 放到 WebGL 上。核心隐喻是“可以进入的知识图册”：每个节点是一块知识信息片，五个 Y 轴层级是不同深度的空间切片，连接线说明知识关系。

设计参考只拆解能力：

- Apple：克制的产品构图、大留白、单一视觉焦点。
- Noomo 与 Awwwards WebGL：通过镜头和空间层次组织叙事。
- Obsidian Graph View：关系可读性与相关内容弱化逻辑。
- Linear 与 Claude：简洁的操作层级、明确的输入和反馈。
- Aceternity UI、Magic UI、React Bits、UIverse：只参考微交互完成度，不复制视觉组件。

设计参数：变化度 8，动效强度 6，信息密度 4。

## 2. 视觉系统

- 页面底色：冷灰纸面 `#e8e9e4`。
- 主文字：石墨黑 `#1d201d`。
- 次级文字：`#50564f`。
- 唯一强调色：朱橙 `#d75b43`。
- 主要容器：`#f6f6f2`，透明材质只用于空间叠层，不在所有控件上滥用。
- 形状规则：面板 14-16px，按钮 7-10px，不使用满屏胶囊按钮。
- 字体：系统无衬线显示字体配中文系统字体；数字和深度值使用等宽字体。

禁止紫蓝 AI 渐变、发光球体、星空粒子、霓虹外发光、三个等宽卡片、装饰性版本号和无意义状态点。

## 3. 三维场景

- 保留 100 个真实节点、图边、相关度和五层 Y 轴数据模型。
- 节点用薄型 BoxGeometry 信息片，不再用 Icosahedron 球体。
- 目标节点尺寸最大，方向节点使用朱橙，课程与技能使用深灰，知识点使用石墨黑，练习尺寸最小。
- 选中节点增加朱橙线框，相关节点保持实体，无关节点降低到 9% 透明度并远离中心。
- 每个知识深度用一个 64×46 的空间切片框组织，切片本身保持极低透明度。
- 关系边分为层级实线和前置/关联虚线；选中路径用朱橙加粗。
- 摄像机使用阻尼插值。全景、目标聚焦、节点聚焦分别使用不同距离；窄屏会自动拉远。

## 4. 页面构图

### 桌面探索页

- 左上：iTeach 品牌标识。
- 顶部居中：当前方向切换器。
- 右上：全景与重设目标。
- 左上第二层：当前目标的大标题和一句解释。
- 左下：五层知识深度索引。
- 右下：规划路径主操作。
- 节点选中后：右侧 430px 空间详情面板。
- 路径生成后：底部横向学习路径，节点可点击并驱动镜头。

### 首次引导

- 全屏双栏，不使用居中的弹窗卡片。
- 左栏承担主叙事、五层知识结构和品牌表达。
- 右栏承担三个画像字段、四个快捷目标和唯一主按钮。
- 输入使用清晰标签和底线结构，错误信息显示在字段下方。

### 移动端

- 顶部只保留品牌和方向切换器。
- 主要操作收敛到底部三键导航。
- 详情面板变为底部 74dvh 面板，内部独立滚动。
- 路径条位于底部导航上方，支持横向滚动。
- 首次引导改为纵向内容，故事和表单顺序不变。

## 5. 比例适配

- 21:9 及更宽：增加左右安全区，表单双栏比例调整为 1.32:0.68，详情宽度 460px。
- 16:9 与 16:10：使用默认构图，顶部 22px，左右 30px。
- 4:3：引导双栏调整为 0.95:1.05，降低标题尺寸，详情面板缩至 390px。
- 小于 1100px：路径条和详情宽度按视口收缩。
- 小于 768px：进入移动构图。
- 高度低于 700px：压缩顶部、表单间距和标题尺寸。
- 手机横屏高度低于 560px：隐藏非关键图例与说明。

所有全屏结构使用 `100dvh`，并处理 `safe-area-inset`。所有动效提供 `prefers-reduced-motion` 降级，透明材质提供 `prefers-reduced-transparency` 实色降级。

## 6. 动效语义

- 目标切换：相关节点靠近并提高对比，无关节点弱化。
- 节点点击：镜头进入知识位置，选中节点出现线框，详情面板同步进入。
- 学习路径：横向路径面板进入，表达由目标到练习的顺序。
- 表单与菜单：只使用 180-420ms 的位移和透明度反馈。

不添加无意义的漂浮、粒子爆炸、循环闪烁或装饰性滚动动画。
