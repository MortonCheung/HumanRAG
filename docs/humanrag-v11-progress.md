## 已确认的共享根因

- 开场用 phase 切换 SceneModel，导航与 Universe 界面在路由交接后才挂载；需要将最终界面预备在同一空间壳内。
- CameraControls 的 stop 会直接采用旧目标终点；setLookAt 未归一化累积方位角。
- 两套流光分别在 pointer/wheel 时冻结时钟和终止脉冲。
- 知识点题库返回把节点 ID 当过滤条件传给父页，错误缩小父级题库。
- V9 领域数据与 V7 ContentRepository 有读取边界；扩展学习入口之前要核对用户节点读取与旧数据兼容。
