# 神经星空与工作区修复 · 2026-09-10

本轮回应导航消失、节点变成暗球、创建节点入口难找，以及知识树学习/题库页缺少美术样式。视觉方向以用户最新描述为准：节点是白色自发光点，关系是突触般的细光线，而不是受灯光照射的实体行星。此说明取代此前“玉色多面体材质”的方向，不改变知识模型或教学规则。

## 落地范围

- 导航：移除桌面与手机共用的原生 `details`。桌面使用永久显示的容器，手机只有一份受控展开状态；保留现有 portal 和页面所属动作。补齐缩放时焦点转移、搜索框深色样式、极窄屏按钮排列。
- 新增节点：个人知识树总览、学习和题库的导航均保留入口；编辑器也常驻。存在未保存内容时，“保存”是唯一主操作，“新增节点”仍可见。系统示例继续只读，并明确提示，不绕过原有写入权限。
- 星空：`NodePointField` 从实体多面体改为单批次点着色器；每个真实节点拥有白色亮芯及柔光，颜色仅轻微影响外晕。删除无用场景灯光，限制近景点尺寸。低画质无需 Bloom 也有柔光。
- 关系：保留真实图谱连线与持续流光，降低背景连线权重、加强节点连接处的光感。没有添加不代表知识点的装饰性粒子。
- 知识树预览及编辑器：复用同一 `NeuronStar`，透明拾取区域与视觉分离，保持点击和拖动能力。
- 学习/题库：补齐之前缺失的 `TreePointDirectory` 样式，以标题、真实数量、课程分组和细线目录建立层级；两页仍使用相同知识点教学/练习工作区。搜索、空结果、无题目和未验证状态均保留。
- 全局视觉：中性近黑背景、冷白文字与少量浅青信号；移除顶部金属感渐变、面板灰绿渐变和装饰噪点。
