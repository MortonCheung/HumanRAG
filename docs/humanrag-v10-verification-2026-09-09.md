# HumanRAG 本批施工与验收 · 2026-09-09

本批保留页面职责、知识库层级和现有数据；未发布、未提交 Git，也未重置用户数据。当前仍是 V10 的施工版本，不据此宣布整版视觉与所有设备性能验收完成。

## 已落地

- 开场：预先准备知识空间界面和 Canvas 首帧；开场与结束共用同一空间，时间轴清理不回滚相机终点。运镜采用目标、方向、对数距离协同插值，支持中断与跳过。
- 相机：选点后以该节点为屏幕正中心；节点过小才进一步靠近，不再为详情面板偏移相机目标。知识树预览统一由相机控制器设置机位，绕构图中心观察，避免被控制器覆盖或绕偏心模型旋转导致裁切。
- 导航：单一顶栏的动作槽随真实宿主注册与注销，不再依赖一次性的 DOM 查询。页面使用正向层叠和反向同轨迹返回；路由模块加载完成后才切换，初次直达提供加载状态。学习记录保存入口来源。
- 创建与编辑：提交后只清持久化草稿，不提前清空当前渲染状态，避免返回创建页的竞争；防重复提交；同树步骤共享草稿、不同树隔离；编辑器也按树隔离状态。
- 美术与文案：修复节点材质变黑的颜色配置，统一玉色/灰青灯光、面板层次和控件；关系搜索框补齐深色样式；学习记录移除装饰性口号。遵循前端设计技能的现状审查和克制原则，不为装饰另加粒子或运行时依赖。

## 实际验证

- 最新回归：26 个测试文件、136 项检查通过；包含开场终点/中断与离场状态、选点居中、持续流光进度、三种宽高比例的树预览、创建提交与跨树草稿、顶栏宿主替换及入口常驻、脏数据保护、教学分流及示范暂停等。
- TypeScript 检查、生产构建和 `git diff --check` 通过。构建仍有已安装 lottie-web 内部 `eval` 提示；未为消除提示修改第三方包。
- 浏览器实测：创建测试知识树 → 填写知识点及正文 → 放置 → 创建，只新增一次并进入编辑页；修改名称 → 保存 → 返回知识树 → 关闭后重新加载，名称和正文保留。
- 浏览器实测：390 × 844 下顶栏、返回、溢出菜单及属性切换可用，表单可滚动；恢复默认视口后检查知识库预览完整构图。
- 浏览器实测：拖动测试节点后切换“内容/关系”，位置不回弹；刷新后坐标仍为 `(2.1072366974202223, -11.118403415581644, -0.9848409722953022)`。位置独立即时保存，不把已保存的拖动误判成未保存的内容修改。
- 浏览器实测：首页进入知识空间、节点选中靠近、学习记录返回知识空间；顶栏动作与目标页面匹配。
- 测试数据：本地 `127.0.0.1:4174` 留有“验收测试 · 节点保存”及一个测试节点，便于复查；未删除既有树或记录。

## 用户反馈修复与复查

- 开场交接：结束状态仍保持 Landing 内容退场，直到路由真正卸载，避免导航加载间隙闪回开场文案。中断运镜时读取 CameraControls 的当前机位，而非仍在趋近的终点。
- 节点居中：测试检查桌面和手机相机投影均为 `(0, 0)`；1280 × 720 实测“考研408”位于 `(640, 360)`，390 × 844 位于 `(195, 422)`。手机详情面板从底部展开，顶部约为 456 px，避开节点；移除旧桌面定位规则对手机的覆盖。
- 流光：复用已有 NeuralSignals 和关系曲线，恢复沿真实连线持续运行的亮芯与短尾迹；质量分档控制数量与刷新频率，拖动/滚轮操作时暂停，隐藏页面或低动态模式不持续运行。不是只播放三秒的选中脉冲。
- 导航与创建：桌面操作直接平铺；手机只保留一层溢出操作，创建知识树独立常驻。实测知识库 → 创建 → 返回知识库，入口仍在；自动测试覆盖宽窄屏和页面往返。
- 学习界面：阶段轨迹、正文与初始条件分区、计算依据直接展示；示范中的曲线、窗口数量及新增块同步，保持原有诊断、教学证据和判题逻辑。清除重复的可见表单图例，仍保留读屏名称。
- 教学实测：错误诊断触发对应示范；输入下一轮预测 4 后，图形从第 0 轮的 2 MSS 更新到第 1 轮的 4 MSS；进入引导练习后焦点和滚动位置回到新标题。手机三轮输入等宽，390 px 页面无横向溢出。
- 测试数据：本地浏览器留下本轮 TCP 诊断与示范查看记录，供复查；这不是用户真实学习成绩，也没有伪造掌握状态。
